Which tag suits which basin
  • Wet pond (a permanent pool): natural=water + water=basin, optionally basin=retention — the scheme Guelph's mapped ponds already use.
  • Dry basin (a grass hollow that floods after a storm): landuse=basin + basin=detention. It is not water most days, so not natural=water.
  • Infiltration basin: landuse=basin + basin=infiltration.
  • Constructed wetland: not settled — listed apart, nothing suggested.
  • Either scheme counts as tagged as a basin; a bare natural=water, water=pond or water=reservoir counts as plain water.
  • The City's plan is a subdivision-plan label, not a name — never copy it into name. A creek's City name is a real name: that is the one to add.
